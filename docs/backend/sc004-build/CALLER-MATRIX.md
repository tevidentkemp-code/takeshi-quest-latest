# SC-004 implemented caller boundary

This matrix describes the candidate source, not production deployment status. The retired local prototype is not a release anchor. Gate acceptance and exact revisions are recorded separately.

| Route | Authority class | Actual implementation |
| --- | --- | --- |
| New match / game | CREATE_ONLY_PUBLIC_OR_SCOPED → MATCH_CONTROLLER_REQUIRED | `src/services/sc004-gameplay.js::prepareNewGame` uses `sc004-client.js::createMatch`, then `reserve_game`; the Edge mints authority and SQL mints IDs. The engine waits before its first throw. |
| Roster, join, reorder, current-match display | MATCH_CONTROLLER_REQUIRED | Gameplay `syncRoster` / `updateDisplay`, awaited by router and initial/late-join flows; `sq_sc004_command` locks the issued roster and pending slots. Persistent player rows are not edited. |
| Throws, score, completion, wins | MATCH_CONTROLLER_REQUIRED | Canonical `src/game/engine.js::recordThrow` and `__sqBuildCompletedGamePayload` remain the scorer and payload builder. `completeCurrentGame` freezes the completed board, persists the retry envelope before sending, and waits for atomic acceptance before awards/advance. SQL derives saved scores and match wins. |
| Go timing | MATCH_CONTROLLER_REQUIRED → SERVER_ONLY | Canonical throw history records observational timestamps; `saveGoEvents` calls the durable `logGo` queue. SQL verifies accepted game and roster player, then calls the restricted six-argument `log_player_go`. |
| Ten-argument go RPC | OBSOLETE_REMOVE | No source or external caller remains; owner confirmed browser-only. Closure drops this broken overload. |
| Failed save / restart / empty match cleanup | MATCH_CONTROLLER_REQUIRED | Own pending slot reset/cleanup only. Accepted games are immutable; an unaccepted completion blocks discard and is retryable after reload. |
| Public player creation | CREATE_ONLY_PUBLIC_OR_SCOPED | Router create-player flow → `SQ_SECURITY.createPlayer` → Edge `create_player`. INSERT only; duplicate names cannot overwrite profiles. |
| Persistent profile / initials / avatar / rename / merge / delete | AUTHENTICATED_ADMIN_ONLY | `src/services/admin-auth.js`, `src/app/util.js`, Player Hub and router helpers → `sqAdminAction` → `admin_action` → live Auth session and private allowlist. Browser flags and old player/PIN passwords grant no authority. |
| History edits, archive, reinstate, purge, remove historical player | AUTHENTICATED_ADMIN_ONLY | Engine/router/cloud helpers → exact admin operations in `admin-command.sql`. Historical edits revoke affected controllers; accepted receipts remain immutable. |
| High scores, repair, backfill, import, maintenance | SERVER_ONLY / AUTHENTICATED_ADMIN_ONLY | Ordinary accepted completion derives scores atomically. Read helpers do not run anonymous repairs. Explicit retained repair/import tools call admin operations. Imports are create-only and conflicting historical retries fail. |
| Legacy in-flight recovery | AUTHENTICATED_ADMIN_ONLY, then MATCH_CONTROLLER_REQUIRED | An enrolled owner verifies the saved legacy match and any settings absent from its old schema payload. Recovery binds a new opaque controller to server history/roster/wins and a pending next game. Public UUID adoption is denied. |
| Training Standard / TDB / Select | CREATE_ONLY_PUBLIC_OR_SCOPED → MATCH_CONTROLLER_REQUIRED | Existing training UI/scorer → separate `create_training` / `complete_training` authority, scoped by training ID. Complete or End Early results retain their actual darts and are validated against issued configuration. |
| Visit telemetry | CREATE_ONLY_PUBLIC_OR_SCOPED | Boot visit helper → `visit`; server derives UTC day and deduplicates device/day. No table mutation from the browser. |
| Events | MATCH_CONTROLLER_REQUIRED | `append_event` accepts only an accepted game, saved roster player and dart coordinates. The SQL writer derives identity, kind and points from the accepted board. Direct table insertion is denied. |
| Commentary | MATCH_CONTROLLER_REQUIRED / AUTHENTICATED_ADMIN_ONLY | Actual `commentary_generate` Edge handler authorizes the game before service reads or model use, claims generation once, and rechecks the same actor before committing. No active anonymous browser/external commentary writer was found. |
| Legacy PIN Edge / helper route | OBSOLETE_REMOVE / SERVER_ONLY | `sq-admin-maintenance` returns 410. Old privileged SQL helpers lose PUBLIC/anon/authenticated EXECUTE. They are unreachable through a public PIN route. |
| Direct tables / sequences / writable view | SERVER_ONLY | Closure removes client DML/maintenance grants from 18 tables and `v_games_visible`, removes four sequence mutation grants and 40 write policies. Read-only views are preserved. |
| Ranking, H2H, stats, public Realtime | READ_ONLY | Existing query clients and read RPCs remain; `game_events` / `game_commentary` publication membership and SELECT policies remain. Real Realtime is part of the integration suite. |

The production transport is shared by the browser classic entrypoint and ESM test import. Offline UI tests use an explicitly named transport fixture solely to keep the existing gameplay baseline independent of network availability; those tests do not count toward real-platform acceptance. The separate real-platform suites use actual local Supabase Auth, Edge, PostgREST and Realtime. Only the optional commentary upstream model output is replaced in a separate, local-only fixture endpoint.
